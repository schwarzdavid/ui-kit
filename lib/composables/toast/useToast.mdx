# useToast

Toast util composable to functionally show toasts.

## General Usage

The toasts are rendered by `UiKitOutlet`; see [Installation](?path=/docs/installation--docs) for registering the plugin and placing the outlet.

## Success/Info/Warning/Error Toasts

The ToastComposable comes with four different presets.

### Demo

<Story of={PresetStories.Default} />

### Usage

`useToast(): ToastComposable` returns the four functions `success`, `info`, `warn` and `error`. Each of them is a `ToastFunction`:

`(message: string, options?: Partial<ToastOptions>) => Promise<void>`

The message is passed through vue-i18n: if a matching translation key exists it is translated, otherwise the text is shown verbatim.

**ToastOptions**
<table>
    <thead>
    <tr>
        <th>Property</th>
        <th>Type</th>
        <th>Description</th>
        <th>Default Value</th>
    </tr>
    </thead>
    <tbody>
    <tr>
        <td>timeout</td>
        <td>number</td>
        <td>Time in milliseconds after which the toast disappears</td>
        <td>The plugin option `toast.timeout` (`4000`)</td>
    </tr>
    <tr>
        <td>translateMessage</td>
        <td>boolean</td>
        <td>If the message should be translated</td>
        <td>`true`</td>
    </tr>
    </tbody>
</table>

The returned Promise resolves when the toast disappears, either because its timeout elapsed or because the user closed it. You can ignore it for fire-and-forget toasts or await it to continue after the toast is gone.

### Example implementation

```vue
<template>
    <div class="d-flex ga-4">
        <VBtn color="success" @click="showSuccessToast">Success toast</VBtn>
        <VBtn color="error" @click="showErrorToast">Error toast</VBtn>
    </div>
</template>

<script lang="ts" setup>
    import { useToast } from '@schwarzdavid/ui-kit'

    const toast = useToast()

    function showSuccessToast(): void {
        void toast.success('items.saved')
    }

    async function showErrorToast(): Promise<void> {
        await toast.error('Upload failed', { translateMessage: false, timeout: 8000 })
        void toast.info('You can retry the upload now', { translateMessage: false })
    }
</script>
```
