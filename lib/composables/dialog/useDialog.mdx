# useDialog

Dialog util composable to functionally create dialogs. Every method returns a Promise that settles when the dialog is closed.

## General Usage

The dialogs are rendered by `UiKitOutlet`; see [Installation](?path=/docs/installation--docs) for registering the plugin and placing the outlet.

## Layout

Every dialog shares one shell: a title, a scrolling body and a footer with the buttons in the order tertiary, then primary. Three widths exist, `sm` (440px), `md` (560px) and `lg` (720px); every method accepts a `width` option of type `DialogWidth` (`'sm' | 'md' | 'lg' | number`). Prompt and form dialogs go full screen below Vuetify's `sm` breakpoint. Escape behaves like the cancel button, a click on the backdrop does nothing.

## DialogComposable::info()

Info dialogs are only meant to show information to the user or to ask for very simple choices (e.g. override/create new profile). However, **do not** use this function to ask for user confirmation, e.g. to ask the user for confirmation before deleting an entity. The `DialogComposable::confirm` is better suited for these kinds of requirement.

#### Simple Info Dialog

`dialog.info(title: string, content: string): Promise<null>`

By calling this function, a info dialog will be created with your defined title and content. Both are passed through vue-i18n: if a matching translation key exists it is translated, otherwise the text is shown verbatim.

`InfoDialogContent` in this example declares `defineProps<{ foo: number }>()`, so `props` must be passed.

```vue
<template>
    <div class="d-flex gc-4">
        <VBtn color="primary" @click="openTextDialog">Text content</VBtn>
        <VBtn color="primary" @click="openComponentDialog">Component content</VBtn>
        <VBtn color="primary" @click="openAdditionalCtaDialog">Additional actions</VBtn>
        <VBtn color="primary" @click="openChoiceCtaDialog">Simple Choice</VBtn>
    </div>
    <p v-if="actionCount" class="mt-4">Action triggered {{ actionCount }} times</p>
    <p v-if="pill" class="mt-4">You chose: {{ pill }}</p>
</template>

<script lang="ts" setup>
    import { ref } from 'vue'
    import { useDialog } from '@schwarzdavid/ui-kit'
    import InfoDialogContent from './InfoDialogContent.vue'

    const dialog = useDialog()
    const pill = ref<string | null>(null)
    const actionCount = ref(0)

    function openTextDialog(): void {
        void dialog.info('Text Dialog', 'Lorem ipsum...')
    }

    function openComponentDialog(): void {
        void dialog.info({
            title: 'Component Dialog',
            component: InfoDialogContent,
            props: {
                foo: 5,
            },
        })
    }

    function openAdditionalCtaDialog(): void {
        void dialog.info({
            title: 'Additional Actions',
            content: 'Lorem ipsum...',
            additionalCta: [
                {
                    text: 'Trigger action',
                    translateText: false,
                    action: () => { actionCount.value++ },
                },
            ],
        })
    }

    async function openChoiceCtaDialog(): Promise<void> {
        pill.value = await dialog.info<string>({
            title: 'Choice Cta',
            content: 'You take the blue pill ... the story ends. You take the red pill ... you stay in wonderland',
            defaultCta: false,
            additionalCta: [
                {
                    text: 'Red pill',
                    translateText: false,
                    value: 'Red Pill',
                },
                {
                    text: 'Blue pill',
                    translateText: false,
                    value: 'Blue Pill',
                },
            ],
        })
    }
</script>
```

## DialogComposable::form()

Form dialogs render a form component of your own inside a dialog with a cancel and a save button. They validate the form with Vuelidate, read the value from the component and optionally run an asynchronous action (e.g. an API call) before closing.

### Demo
<Story of={FormDialogStories.Default} />

### Usage

`dialog.form<R, T = R, RejectOnEmpty extends boolean = false>(options: FormDialogProps<R, T, RejectOnEmpty>): Promise<RejectOnEmpty extends true ? R : R | null>`

`T` is the value your form component produces and `R` is the value the Promise resolves with. Without an `action`, `R` equals `T`.

Your form component registers a `finish` function with `useDialogForm(finish)`. The composable returns `submit()` and `loading`; it throws when the component is not rendered inside a form dialog. The dialog body is a `<form>`, so pressing Enter in a field submits as well.

When the user submits, the dialog:

1. runs `useVuelidate().$validate()`, which validates every Vuelidate instance created inside your component. If the form is invalid, the dialog stays open.
2. calls your `finish()` to get the value of type `T`.
3. calls `action(value)` if provided and resolves with its result, otherwise resolves with the value from `finish()`.

While `finish()` and `action` run, the submit button shows its loading state, cancel and the close icon are disabled and Escape is ignored. The busy state lasts at least `loading.delay` milliseconds of the plugin options. If `finish()` or `action` throws, the dialog stays open and shows an error alert at the top of the body with the `saveFailed` message as title and the error's message as text (or the `unknownError` message when the thrown value carries none); the user's input is kept.

When the user closes the dialog with the cancel button, the close icon or Escape, the Promise resolves with `null`. With `rejectOnEmpty: true` it rejects instead, and it also rejects when the result is `null`.

```vue
        name: '',
        age: null,
        date: new Date(),
    })

    const v = useVuelidate({
        name: { required, minLength: minLength(5), maxLength: maxLength(8) },
        age: { required },
        date: { required },
    }, state)

    useDialogForm(() => state.value.name)
</script>
```

The calling component opens the dialog and stores the result:

```vue
<template>
    <VBtn variant="flat" color="primary" @click="openFormDialog">New profile</VBtn>
    <p v-if="result !== null" class="mt-4">Saved name: {{ result }}</p>
</template>

<script lang="ts" setup>
    import { ref } from 'vue'
    import { useDialog } from '@schwarzdavid/ui-kit'
    import FormDialogContent from './FormDialogContent.vue'

    const dialog = useDialog()
    const result = ref<string | null>(null)

    async function openFormDialog(): Promise<void> {
        result.value = await dialog.form<string>({
            title: 'New profile',
            translateTitle: false,
            component: FormDialogContent,
        })
    }
</script>
```

To persist the value before the dialog closes, pass an `action`. The dialog then resolves with the action's result, and a thrown error stays inside the dialog:

```ts
const profile = await dialog.form<Profile, string>({
    title: 'profile.create',
    component: FormDialogContent,
    action: name => api.createProfile({ name }),
})
```
