# Vuetify theme

`@schwarzdavid/ui-kit/vuetify` carries the Mail Admin design as a `createVuetify` configuration. It is a separate entry so that applications with their own theme never load it. It requires Vuetify 4: the font variables `--v-font-body` and `--v-font-heading`, the Material 3 typography roles, the `scrim` and `opacity` dialog props and the `.border-<color>` utilities do not exist in Vuetify 3.

```ts
import { createVuetify } from 'vuetify'
import { createVuetifyOptions } from '@schwarzdavid/ui-kit/vuetify'

export const vuetify = createVuetify(createVuetifyOptions({
    theme: { defaultTheme: 'light' },
    defaults: { VDataTableServer: { itemsPerPage: 50 } },
}))
```

Every colour token is a Vuetify theme colour, so it is available as `color="ink-muted"`, as the class `text-ink-muted` and as `rgb(var(--v-theme-ink-muted))`. Three rules carry the design: yellow is a fill only (`variant="flat" color="primary"` with `on-primary` text), `primary-container` marks "you are here", and status colours never appear without a word.

## Component gallery

Stock Vuetify components with this configuration, the SASS settings and the CSS from [Known gaps](#known-gaps). Nothing below sets colours or variants beyond what the examples name; everything else comes from the defaults. Switch the background in the toolbar to "Dark" to see the dark theme.

### Colours

The theme colours of the active theme. Use them as `color="…"`, `text-…`, `bg-…` or `rgb(var(--v-theme-…))`.

<Story of={GalleryStories.Colors} />

### Typography

The Material 3 roles with the weights and sizes from the SASS settings. The `code` roles come from the Known gaps CSS.

<Story of={GalleryStories.Typography} />

### Buttons

Outlined `ink` is the default (secondary). Use `variant="flat" color="primary"` for the one primary action of a view and `variant="text"` for tertiary actions. Button groups get the secondary border with dividers between their buttons. A disabled filled button turns `disabled-surface` with `ink-disabled` text through the Known gaps CSS.

<Story of={GalleryStories.Buttons} />

```vue
<VBtn variant="flat" color="primary">Primary</VBtn>
<VBtn>Secondary</VBtn>
<VBtn variant="text">Tertiary</VBtn>
<VBtn variant="flat" color="error">Destructive</VBtn>
```

### Text fields and selects

All fields are outlined and comfortable, focused in `focus` and hide their details until there is a message.

<Story of={GalleryStories.Fields} />

### Selection controls

Checkboxes and radios use `ink`. Switches are inset with an `ink` track when on and a `border-strong` track when off.

<Story of={GalleryStories.Selection} />

### Feedback

Alerts are tonal and compact, their titles use the `title-small` size. Status chips carry a word, never only a colour. Progress tracks and skeleton bones use Vuetify's 12 % instead of the theme's opaque border opacity.

<Story of={GalleryStories.Feedback} />

### Containers and navigation

Cards and expansion panels are flat with a border and the `lg` radius. The active list item is `primary-container` ("you are here") with `ink` text, also in the menus of `VSelect`, `VAutocomplete` and `VCombobox`; dividers use `border`.

<Story of={GalleryStories.Containers} />

### Data table

Comfortable density with row hover; `VDataTableServer` additionally defaults to 25 rows per page.

<Story of={GalleryStories.DataTable} />

### Menus, tooltips, snackbars and dialogs

Menus open 4px from their activator, tooltips open above after 300 ms, snackbars are inverse at the bottom. A plain `VDialog` uses the `scrim` backdrop at 48 %; for dialogs from script use [useDialog](?path=/docs/composables-usedialog--docs).

## SASS settings

Some parts of the design Vuetify only exposes through SASS: the typography scale (weights and sizes of `text-headline-small`, `text-title-large`, …), the radius scale (`rounded="md"` 6px, `rounded="lg"` 10px), the alert title size (`title-small` instead of `headline-small`), the opaque switch track and the skeleton bone colour. `@schwarzdavid/ui-kit/vuetify/settings.scss` forwards `vuetify/settings` with all of them. Point `vite-plugin-vuetify` at a local file that forwards it:

```scss
@forward '@schwarzdavid/ui-kit/vuetify/settings.scss';
```

```ts
import vuetify from 'vite-plugin-vuetify'

export default defineConfig({
    plugins: [
        vue(),
        vuetify({ styles: { configFile: 'src/styles/settings.scss' } }),
    ],
})
```

`configFile` is resolved against the project root, so `node_modules/@schwarzdavid/ui-kit/dist/vuetify/settings.scss` works as well. Both `@schwarzdavid/ui-kit/vuetify/settings.scss` and the extensionless `@schwarzdavid/ui-kit/vuetify/settings` resolve through the package exports. Without the settings file the typography roles keep Vuetify's weights (400/500 instead of 600), the radii are 4px and 8px instead of 6px and 10px, alert titles stay at the `headline-small` size, the switch track is drawn at 60 % opacity and skeleton bones are solid `on-surface`; everything else applies.

## Fonts

Install `@fontsource/noto-sans` (400, 500, 600) and `@fontsource/jetbrains-mono` (400, 500) and import their CSS files in your entry; see [Installation](?path=/docs/installation--docs).

## Known gaps

The following details of the design cannot be expressed through `createVuetify` options or the settings file. The dialogs and toasts of this library carry them in their own stylesheet; for the rest of your application copy this snippet into your global CSS.

1. The field outline at rest is drawn at 38 % opacity by Vuetify. The defaults use `baseColor: 'ink'` as the closest approximation.
2. The border of outlined (secondary) buttons is `currentColor`, which is `ink`, instead of `border-strong`.
3. Disabled filled buttons keep their colour (`bg-primary` wins over Vuetify's disabled style) and get a dark overlay, so a disabled primary button turns olive instead of `disabled-surface` with `ink-disabled` text.
4. The active list item gets `bg-primary-container` from the defaults, but Vuetify also draws its activated overlay in the `ink` text colour on top, which darkens the yellow.
5. The active page of `VPagination` gets an overlay in its text colour at `--v-border-opacity`, which the theme sets to 1 for exact border colours, so the page number disappears in a solid block.
6. Monospace for `code`, `kbd`, `pre` and the `text-code-medium` / `text-code-small` roles.
7. Slower animations under `prefers-reduced-motion`.

```css
.v-field:not(.v-field--focused):not(.v-field--error) .v-field__outline {
    color: rgb(var(--v-theme-border-strong));
    --v-field-border-opacity: 1;
}

.v-btn--variant-outlined {
    border-color: rgb(var(--v-theme-border-strong));
}

.v-btn--disabled:is(.v-btn--variant-flat, .v-btn--variant-elevated) {
    background-color: rgb(var(--v-theme-disabled-surface));
    color: rgb(var(--v-theme-ink-disabled));
}

.v-btn--disabled:is(.v-btn--variant-flat, .v-btn--variant-elevated) .v-btn__overlay {
    opacity: 0;
}

.v-list-item--active.bg-primary-container > .v-list-item__overlay {
    opacity: 0;
}

.v-pagination__item--is-active .v-btn__overlay {
    opacity: var(--v-activated-opacity);
}

code,
kbd,
pre,
.text-code-medium,
.text-code-small {
    font-family: 'JetBrains Mono', ui-monospace, 'SF Mono', Menlo, Consolas, monospace;
    font-variant-ligatures: none;
}

.text-code-medium {
    font-size: 0.8125rem;
    line-height: 1.25rem;
}

.text-code-small {
    font-size: 0.75rem;
    line-height: 1rem;
}

@media (prefers-reduced-motion: reduce) {
    .v-skeleton-loader__bone::after,
    .v-progress-circular--indeterminate > svg,
    .v-progress-linear__indeterminate {
        animation-duration: 4s !important;
    }
}
```
