# Configuration

`createUIKit(options?: PartialDeep<PluginOptions>)` deep-merges the passed options over the defaults, so you only pass the values you want to change.

```ts
app.use(createUIKit({
    loading: { delay: 500 },
    toast: { timeout: 6000 },
    i18n: { messages: { close: 'buttons.close' } },
}))
```

## Plugin options

    <thead>
    <tr>

    <tr>
        <td>loading.delay</td>
        <td>number | false</td>
        <td>Minimum duration in milliseconds for which `useLoading` keeps `loading` true, so that the spinner does not flicker on fast actions. `false` disables the minimum duration.</td>
        <td>`2000`</td>
    </tr>
    <tr>
        <td>loading.overlay</td>
        <td>boolean</td>
        <td>Whether `useLoading` actions show the global loading overlay while they run.</td>
        <td>`false`</td>
    </tr>
    <tr>
        <td>toast.timeout</td>
        <td>number</td>
        <td>Time in milliseconds after which a toast disappears.</td>
        <td>`4000`</td>
    </tr>
    <tr>
        <td>i18n.messages</td>
        <td>Record&lt;PluginI18nMessageKey, string&gt;</td>
        <td>Translation keys of the default dialog button labels. See below.</td>
        <td>See below</td>
    </tr>
    </tbody>
</table>

`useLoading` and `useToast` accept per-call options that override these defaults.

## i18n message keys

The dialogs label their default buttons with the following translation keys. The keys are looked up in the global vue-i18n instance; a key that does not exist in any locale is rendered verbatim, so you can also pass plain text.

<table>
    <thead>
    <tr>
        <th>Message</th>
        <th>Used for</th>
        <th>Default key</th>
    </tr>
    </thead>
    <tbody>
    <tr>
        <td>yes</td>
        <td>Confirm button of `confirm()`</td>
        <td>`common.yes`</td>
    </tr>
    <tr>
        <td>no</td>
        <td>Reject button of `confirm()`</td>
        <td>`common.no`</td>
    </tr>
    <tr>
        <td>cancel</td>
        <td>Abort button of `prompt()` and `form()`</td>
        <td>`action.cancel`</td>
    </tr>
    <tr>
        <td>close</td>
        <td>Default button of `info()` and the label of the close icon of every dialog</td>
        <td>`action.close`</td>
    </tr>
    <tr>
        <td>save</td>
        <td>Save button of `prompt()` and `form()`</td>
        <td>`action.save`</td>
    </tr>
    </tbody>
</table>

A matching vue-i18n message object for the defaults looks like this:

```json
{
    "common": {
        "yes": "Yes",
        "no": "No"
    },
    "action": {
        "cancel": "Cancel",
        "close": "Close",
        "save": "Save"
    }
}
```

## Validation messages

The validators entry is configured separately with `setGlobalValidationSettings`, because the validators are plain functions that are used outside of the plugin. Call it once at startup with the translation function of your vue-i18n instance:

```ts
import { setGlobalValidationSettings } from '@schwarzdavid/ui-kit/validators'

setGlobalValidationSettings({
    t: (path, params) => i18n.global.t(path, params),
    message: { prefix: 'validation', transform: 'snake_case' },
})
```

See [validators](?path=/docs/validators--docs) for the message path rules and the list of validators.
