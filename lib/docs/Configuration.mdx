# Configuration

`createUIKit(options?: CreateUIKitOptions)` deep-merges the passed options over the defaults, so you only pass the values you want to change. The `components` option is the exception: each component is replaced as a whole, never merged.

```ts
app.use(createUIKit({
    loading: { delay: 500 },
    toast: { timeout: 6000, errorTimeout: 10000 },
    i18n: { messages: { close: 'buttons.close' } },
    components: { dialog: { confirm: MyConfirmDialog } },
}))
```

## i18n message keys

The dialogs and toasts label their default buttons with the following translation keys. The keys are looked up in the global vue-i18n instance; a key that does not exist in any locale is rendered verbatim, so you can also pass plain text.

<table>
    <thead>
    <tr>
        <th>Message</th>
        <th>Used for</th>
        <th>Default key</th>
    </tr>
    </thead>
    <tbody>
    <tr>
        <td>yes</td>
        <td>Confirm button of `confirm()`</td>
        <td>`common.yes`</td>
    </tr>
    <tr>
        <td>no</td>
        <td>Reject button of `confirm()`</td>
        <td>`common.no`</td>
    </tr>
    <tr>
        <td>cancel</td>
        <td>Cancel button of `prompt()` and `form()`</td>
        <td>`action.cancel`</td>
    </tr>
    <tr>
        <td>close</td>
        <td>Default button of `info()`, the label of the close icon of every dialog and of the dismiss button of every toast</td>
        <td>`action.close`</td>
    </tr>
    <tr>
        <td>save</td>
        <td>Save button of `prompt()` and `form()`</td>
        <td>`action.save`</td>
    </tr>
    <tr>
        <td>saveFailed</td>
        <td>Title of the error shown inside `form()` when `finish()` or `action` throws</td>
        <td>`dialog.saveFailed`</td>
    </tr>
    <tr>
        <td>unknownError</td>
        <td>Text of that error when the thrown value is neither an `Error`, a string nor an object with a `message`</td>
        <td>`error.unknown`</td>
    </tr>
    </tbody>
</table>

A matching vue-i18n message object for the defaults looks like this:

```json
{
    "common": {
        "yes": "Yes",
        "no": "No"
    },
    "action": {
        "cancel": "Cancel",
        "close": "Close",
        "save": "Save"
    },
    "dialog": {
        "saveFailed": "Couldn't save"
    },
    "error": {
        "unknown": "Something went wrong"
    }
}
```

## Validation messages

The validators entry is configured separately with `setGlobalValidationSettings`, because the validators are plain functions that are used outside of the plugin. Call it once at startup with the translation function of your vue-i18n instance:

```ts
import { setGlobalValidationSettings } from '@schwarzdavid/ui-kit/validators'

setGlobalValidationSettings({
    t: (path, params) => i18n.global.t(path, params),
    message: { prefix: 'validation', transform: 'snake_case' },
})
```

See [validators](?path=/docs/validators--docs) for the message path rules and the list of validators.
