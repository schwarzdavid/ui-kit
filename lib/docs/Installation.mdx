# Installation

`@schwarzdavid/ui-kit` provides Vue 3 + Vuetify composables for promise-based dialogs, toasts, loading states and translated Vuelidate validators, plus an opt-in Vuetify configuration that carries the Mail Admin design.

## Install the package

```sh
npm install @schwarzdavid/ui-kit
```

The package is published as ESM only. The following peer dependencies must be installed in your application:

## Fonts

The design uses Noto Sans and JetBrains Mono. The library does not ship them; install and import them in your application:

```sh
npm install @fontsource/noto-sans @fontsource/jetbrains-mono
```

```ts
import '@fontsource/noto-sans/400.css'
import '@fontsource/noto-sans/500.css'
import '@fontsource/noto-sans/600.css'
import '@fontsource/jetbrains-mono/400.css'
import '@fontsource/jetbrains-mono/500.css'
```

Without the fonts the theme falls back to the system sans-serif stack.

## Register the plugin

Register Vuetify and vue-i18n, then install the plugin with `app.use(createUIKit(options))` and import the styles entry once. All options are optional; see [Configuration](?path=/docs/configuration--docs) for the full list and their defaults. The example uses the Mail Admin Vuetify configuration; a plain `createVuetify()` works too, the dialogs and toasts then fall back to your theme's `primary`, `on-surface` and `surface-variant` colours.

```ts
import { createApp } from 'vue'
import { createVuetify } from 'vuetify'
import { createI18n } from 'vue-i18n'
import { createUIKit } from '@schwarzdavid/ui-kit'
import { createVuetifyOptions } from '@schwarzdavid/ui-kit/vuetify'
import 'vuetify/styles'
import '@schwarzdavid/ui-kit/styles'
import App from './App.vue'

createApp(App)
    .use(createVuetify(createVuetifyOptions()))
    .use(createI18n({ legacy: false, locale: 'en', messages: { en: {} } }))
    .use(createUIKit())
    .mount('#app')
```

## Place the outlet

The composables do not render anything themselves. Mount `UiKitOutlet` exactly once inside `VApp`, usually in your root component (`App.vue`). It renders every dialog, every toast and the global loading overlay.

```vue
<template>
    <VApp>
        <VMain>
            <RouterView />
        </VMain>
        <UiKitOutlet />
    </VApp>
</template>

<script lang="ts" setup>
    import { UiKitOutlet } from '@schwarzdavid/ui-kit'
</script>
```

## Where composables can be called

`useDialog`, `useToast`, `useLoading` and `useLoadingOverlay` read the plugin state through `inject`. Call them inside `setup()` (including `<script setup>`) or inside `app.runWithContext()`. Anywhere else, or when the plugin was not installed, they throw:

```text
@schwarzdavid/ui-kit is not available in this context. Install it with app.use(createUIKit()) and call its composables inside setup() or app.runWithContext().
```

For example, to show a toast from a router guard:

```ts
router.afterEach((to, from, failure) => {
    if (failure) {
        app.runWithContext(() => useToast().error('navigation.failed'))
    }
})
```
